# Website Report · VietNamNet (app cài đặt)

Vỏ app (PWA) để cài **Website Report** lên máy tính / điện thoại như một ứng dụng riêng.

- Link app: https://accvnn.github.io/website-report/
- Trang thật chạy trên Google Apps Script; link gốc nằm ở biến `APP` trong `index.html`.
- Có thể kèm tham số, ví dụ `?mod=tb`, `?mod=au` để mở thẳng chức năng.

**Cách cài:** mở link app bằng Chrome/Edge → biểu tượng cài đặt trên thanh địa chỉ (hoặc menu → Cài đặt ứng dụng).
Điện thoại: Chrome Android → Thêm vào màn hình chính · iPhone Safari → Chia sẻ → Thêm vào MH chính.
